# Agronexia brand assets

Assets match the Android launcher mark: green circular background with white outer seed and light-green inner seed.

| File | Use |
|------|-----|
| `agronexia-mark.svg` | Full mark (108×108 viewBox) — logos, splash, large UI |
| `agronexia-mark-32.svg` | Same mark, 32×32 default size — header / nav |
| `favicon-32.png` | Browser favicon (32×32) |
| `favicon-192.png` | PWA / high-res favicon (192×192) |

**Colors**

- Background green: `#1F8A45`
- Outer seed: `#FFFFFF`
- Inner seed: `#A5D6A7`

Source paths mirror `ic_launcher_foreground` (seed/sprout mark).
